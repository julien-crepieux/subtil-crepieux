# subtil-crepieux

Site statique retraçant l'histoire de la société Subtil Crépieux (Lyon, puis Chassieu, depuis 1929), fabricant de stérilisateurs hospitaliers.

- `index.html` : la page (origines, chronologie, innovations, métiers, international, charte, sources)
- `css/style.css` : styles (thème clair et sombre)
- `js/main.js` : filtre de la chronologie par époque et navigation

## Voir le site en local

```bash
python -m http.server 8080
```

puis ouvrir http://localhost:8080.

Les contenus proviennent des pages historiques du site officiel subtil-crepieux.com, archivées par Internet Archive (liens dans la section Sources).
